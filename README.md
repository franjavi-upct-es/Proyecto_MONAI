# lungseg — Lung Tumor Segmentation & Classification

3D segmentation of NSCLC tumours on CT (MSD Task06_Lung, 64 cases) with MONAI
1.5+, plus a Phase 5 radiomic / deep-feature classifier (LIDC-IDRI) and a
Phase 6 ablation study.

This repo replaces an earlier `scripts/monai_pipeline/` codebase that maxed
out at DSC ≈ 0.14 with the symptoms diagnosed in
[REPORT_DIAGNOSIS.md](REPORT_DIAGNOSIS.md). The new `src/lungseg/` package is
Hydra-driven and tested.

## Setup

```bash
pip install -e .[dev]                  # core + dev tooling
# optional extras:
pip install -e .[radiomics]            # Phase 5: pyradiomics, pylidc, xgboost
pip install -e .[demo]                 # gradio demo
pip install -e .[kaggle]               # wandb for cloud runs
```

## Data

Place the MSD Task06_Lung dataset at `data/raw/Task06_Lung/`. The original tar
from the MONAI download lives in `data/raw/Task06_Lung.tar`. Fixed patient-level
splits are generated by B2 into `data/splits/fold_{0..4}.json` (committed).

`data/raw/` and `data/processed/` are gitignored. Do not edit files under
`data/raw/`.

## Commands

```bash
pytest tests/ -q                                              # tests
ruff check src/                                               # lint
python -m lungseg.cli --help                                  # CLI help

python -m lungseg.cli train --config-name=sanity              # overfit 1 batch
python -m lungseg.cli train experiment=phase4_full            # full Phase 4
python -m lungseg.cli ablate -m experiment=phase6_ablation \
    seed=0,1,2 data_fraction=0.25,0.5,1.0                     # Hydra multirun
```

## Hard rules

See [.claude/CLAUDE.md](.claude/CLAUDE.md) for the full list. Highlights:

- Patient-level GroupKFold; never random per-image.
- HU clipping `a_min=-1024, a_max=400` (justified deviation from nnU-Net's
  325).
- `RandFlipd spatial_axis=0` (LR) is forbidden on chest CT.
- MSD Task06 has NO benign/malignant labels.
